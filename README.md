AyuChain - Team Responsibilities 
The responsibilities are divided so that each member works independently while integrating their module with the rest of the system.
Member 1 – Blockchain Developer
•	Learn Solidity, Hardhat, and Ethers.js.
•	Design and develop smart contracts.
•	Create herb batch records on the Polygon Amoy blockchain.
•	Implement ownership transfer between farmer, lab, and manufacturer.
•	Connect MetaMask wallet with the application.
•	Test and deploy smart contracts on the Polygon Amoy Testnet.
•	Work with Member 2 to connect blockchain APIs.
Member 2 – Backend Developer
•	Develop REST APIs using Node.js and Express.js.
•	Design the PostgreSQL database.
•	Implement user registration and login using JWT authentication.
•	Manage herb, lab report, and transaction data.
•	Connect the backend with blockchain and IPFS modules.
•	Perform API testing and documentation.
Member 3 – Frontend Developer
•	Design responsive user interfaces using Next.js and Tailwind CSS.
•	Create separate dashboards for Farmer, Lab, Manufacturer, Customer, and Admin.
•	Develop forms for herb registration and report uploads.
•	Integrate QR code scanning and verification page.
•	Display herb locations using Leaflet and OpenStreetMap.
•	Connect frontend with backend APIs.
Member 4 – IPFS, Security & Deployment
•	Upload images and PDF reports to IPFS using Pinata.
•	Generate and manage QR codes for each herb batch.
•	Implement role-based access control and input validation.
•	Perform security testing and bug fixing.
•	Deploy the frontend on Vercel and backend on Render.
•	Prepare project documentation, testing reports, and final presentation.
Team Collaboration
• Member 1 shares blockchain functions with Member 2.
• Member 2 provides APIs for Member 3.
• Member 4 integrates IPFS, QR codes, security, and deployment with all modules.
• All members perform integration testing before the final demonstration.
